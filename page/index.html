Claude Desktop 中文

给 Claude Desktop 装一份简体中文界面。官方安装目录一字不改：插件复制一份客户端到别处， 把中文语言包打进它的界面资源里，并让它的启动校验对得上。

开关

自动安装 / 更新

magpie 启动或打开本页时，检查官方版本；变了就自动重做一份中文副本。

重建一次

副本看着没问题也重做一遍（界面没更新过来时用）。

移除中文副本

删掉复制出来的客户端（约 750 MB）。官方安装不受影响，随时可以再建。

怎么用

  1. 打开「副本\claude.exe」。它就是中文版，配置与会话与官方版共用。
  2. 只影响界面文字，不改功能与网络请求。
  3. 官方版更新后，勾着「自动安装」的话下次启动 magpie 会自动重做。

原理

桌面端的界面语言由 ion-dist.asar 里一份硬编码的 11 项白名单决定，没有中文； 而安装目录同时被 ACL 和 claude.exe 内嵌的 asar 头部 SHA256 校验保护着， 直接改会启动即崩（Integrity check failed for asar archive entry '<header>'）。 所以这里走「复制副本 + 重打包 + 同步内嵌哈希」：官方包不动，副本自洽。
